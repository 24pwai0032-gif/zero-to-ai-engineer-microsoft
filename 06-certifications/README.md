# Stage 5: Certifications

Certifications aren't required to be good at this, but they're a useful checkpoint and they help on a CV/LinkedIn, especially early in your career.

## Suggested order

1. **[AI-900 / AI-901: Microsoft Azure AI Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-fundamentals/?wt.mc_id=studentamb_649262)** — take this after Stage 0. No coding required.
2. **[AI-102: Designing and Implementing a Microsoft Azure AI Solution](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-engineer/?wt.mc_id=studentamb_649262)** — take this after Stages 1–3. This is the real "AI Engineer" credential.
3. **[DP-100: Designing and Implementing a Data Science Solution on Azure](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-scientist/?wt.mc_id=studentamb_649262)** — if you're leaning more toward data science than engineering, take this instead of or alongside AI-102.

## Notes
- AI-900 usually retires and gets replaced periodically (AI-901 is the newer version as of 2026) — always check the current exam code on the certification page before booking.
- These are official Microsoft certification pages, not third-party prep courses. Use the free practice assessments linked on each page before paying for the exam.

## That's the full pathway
If you've gone through all six stages, you have a genuinely solid, practical foundation in AI on Microsoft's stack — from fundamentals to production agents. From here, specialize based on what you're actually building.
