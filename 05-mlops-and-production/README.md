# Stage 4: MLOps & Production

Everything before this stage gets a model or an agent working. This stage is about keeping it working, at scale, without babysitting it manually.

## What you'll be able to do after this stage
- Apply DevOps principles (source control, CI/CD) to ML projects
- Automate training and deployment with GitHub Actions
- Monitor and govern agents/models running in production

## Resources

1. **[End-to-end machine learning operations (MLOps) with Azure Machine Learning](https://learn.microsoft.com/en-us/training/paths/build-first-machine-operations-workflow/?wt.mc_id=studentamb_649262)** — the core MLOps path: source control, CI/CD, and automated deployment for ML projects.
2. **[Manage agents at scale](https://learn.microsoft.com/en-us/azure/foundry/control-plane/how-to-manage-agents?wt.mc_id=studentamb_649262)** — agent inventory, health monitoring, and lifecycle operations in the Foundry portal.
3. **[Run AI workloads on Azure infrastructure](https://learn.microsoft.com/en-us/azure/well-architected/ai/get-started?wt.mc_id=studentamb_649262)** — Well-Architected guidance for choosing compute, data, and ops approach for training and inference.

## Prerequisites
Stage 1 (Machine Learning) at minimum. Familiarity with Git/GitHub is expected.
