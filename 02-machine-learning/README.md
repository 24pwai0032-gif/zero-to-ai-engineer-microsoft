# Stage 1: Machine Learning

This is where things get hands-on. You'll train and deploy your first models.

## What you'll be able to do after this stage
- Describe core ML concepts (regression, classification, clustering)
- Use Azure Machine Learning to train, evaluate, and deploy a model
- Run AutoML and understand when to use it vs. custom training

## Resources

1. **[Fundamentals of machine learning](https://learn.microsoft.com/en-us/training/modules/fundamentals-machine-learning/?wt.mc_id=studentamb_649262)** — core concepts module, no prior ML background assumed.
2. **[Explore and configure the Azure Machine Learning workspace](https://learn.microsoft.com/en-us/training/modules/intro-to-azure-machine-learning-service/?wt.mc_id=studentamb_649262)** — get comfortable with the Azure ML studio.
3. **[Train and deploy a machine learning model with Azure Machine Learning](https://learn.microsoft.com/en-us/training/paths/train-deploy-machine-learning-model/?wt.mc_id=studentamb_649262)** — full path taking you from raw data to a deployed endpoint.

## Prerequisites
Basic Python is helpful but not required for the first two resources.

## Time estimate
8–10 hours.
