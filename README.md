# AI Learning Pathway with Microsoft

A free, structured roadmap for anyone starting out in AI, built entirely from official Microsoft Learn material. No paid courses, no fluff. Follow the stages in order, or jump to the one you need.

Maintained by [Syed Hassan Tayyab](https://github.com/) — AI Engineer, Co-founder at Cortexium, AI Lead at MLSA UET Peshawar.

## Why this exists

Microsoft has an enormous amount of free AI training scattered across Learn, GitHub, and Foundry docs. Most beginners either don't know it exists or don't know what order to take it in. This repo is that order.

## How to use this

Each folder below is a stage. Work through them top to bottom if you're starting from zero. If you already know the basics, skip to the stage that matches where you are.

## Roadmap

| Stage | Folder | What you'll learn | Level |
|---|---|---|---|
| 0 | [AI Fundamentals](./01-ai-fundamentals) | Core AI/ML concepts, responsible AI, Azure AI overview | Beginner |
| 1 | [Machine Learning](./02-machine-learning) | ML concepts, Azure Machine Learning, model training | Beginner–Intermediate |
| 2 | [Generative AI](./03-generative-ai) | LLMs, prompt engineering, Azure OpenAI | Intermediate |
| 3 | [AI Agents & Foundry](./04-ai-agents-and-foundry) | Building and orchestrating AI agents on Microsoft Foundry | Intermediate–Advanced |
| 4 | [MLOps & Production](./05-mlops-and-production) | CI/CD for ML, deployment, monitoring | Advanced |
| 5 | [Certifications](./06-certifications) | Which Microsoft certs to aim for and in what order | All levels |

## Ground rules for contributing
