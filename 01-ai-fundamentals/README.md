# Stage 0: AI Fundamentals

Start here if you're completely new to AI. No coding required for this stage.

## What you'll be able to do after this stage
- Describe what AI actually is and the common workload types (vision, NLP, generative, etc.)
- Explain responsible AI principles
- Navigate the Azure AI portfolio and know what each service is for

## Resources

1. **[Discover AI fundamentals](https://learn.microsoft.com/en-us/training/paths/get-started-with-artificial-intelligence-on-azure/?wt.mc_id=studentamb_649262)** — official Microsoft Learn path. Covers AI workloads, ML basics, and where Azure fits in.
2. **[Learn responsible AI](https://learn.microsoft.com/en-us/training/paths/responsible-ai-business-principles/?wt.mc_id=studentamb_649262)** — principles every AI builder should know before shipping anything.
3. **[Get an introduction to generative AI](https://learn.microsoft.com/en-us/training/paths/introduction-generative-ai/?wt.mc_id=studentamb_649262)** — light intro, sets you up for Stage 2.
4. **[Introduction to AI in Azure (AI-900T00 course)](https://learn.microsoft.com/en-us/training/courses/ai-900t00/?wt.mc_id=studentamb_649262)** — the full self-paced course version, useful if you want the certification later.

## Time estimate
4–6 hours if you go through everything once.
