# Stage 3: AI Agents & Microsoft Foundry

This is the fastest-moving part of the Microsoft AI stack right now. Agents that reason, use tools, and collaborate with each other are becoming the default way real AI products get built.

## What you'll be able to do after this stage
- Build and test an agent in Microsoft Foundry
- Connect custom tools and MCP servers to an agent
- Design multi-agent systems where agents collaborate on a task
- Ground an agent in your own private data securely

## Resources

1. **[Develop AI agents on Azure](https://learn.microsoft.com/en-us/training/paths/develop-ai-agents-on-azure/?wt.mc_id=studentamb_649262)** — the core learning path. Covers Foundry Agent Service and the Microsoft Agent Framework end to end.
2. **[Developing in Agentic AI Systems](https://learn.microsoft.com/en-us/training/paths/gh-developing-agentic-systems-1/?wt.mc_id=studentamb_649262)** — designing, deploying, and managing agentic systems across the full dev lifecycle.
3. **[Develop a multi-agent solution with Foundry Agent Service](https://learn.microsoft.com/en-us/training/modules/develop-multi-agent-azure-ai-foundry/?wt.mc_id=studentamb_649262)** — connected agents collaborating on a single task instead of one agent doing everything.
4. **[Deploy private agentic retrieval for Foundry IQ](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/foundry-iq-tutorial-private-overview?wt.mc_id=studentamb_649262)** — grounding agents in your own private data with Azure AI Search.
5. **[Integrate MCP tools with Azure AI Agents](https://learn.microsoft.com/en-us/training/modules/connect-agent-to-mcp-tools/?wt.mc_id=studentamb_649262)** — connecting agents to external tools via Model Context Protocol.

## Prerequisites
Stage 2 (Generative AI). Basic Python or C# helps for the SDK exercises.
