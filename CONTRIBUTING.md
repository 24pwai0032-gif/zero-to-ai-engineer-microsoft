# Contributing

This repo stays useful only if it stays clean. Before opening a PR:

## What's allowed
- Official Microsoft Learn modules, learning paths, and courses
- Official Microsoft documentation pages (learn.microsoft.com)
- Official Microsoft GitHub repos (github.com/microsoft/...)
- Microsoft Reactor / Microsoft Ignite / Microsoft Build sessions, if publicly archived

## What's not allowed
- Paid third-party courses (Udemy, Coursera, Pluralsight, etc.), even if they cover the same exam
- Shortened/tracked URLs from anyone other than the maintainer
- Homepage links with no specific content (e.g. just "azure.com") — link to the actual module or article
- Duplicate resources already covered in another stage

## How to submit a resource
1. Fork the repo
2. Add your link to the relevant stage's `README.md`, in the same format as existing entries (bold title, link, one-line description)
3. Open a PR explaining why the resource belongs at that stage
4. If it doesn't fit an existing stage, propose a new one in the PR description

## Reporting a dead link
Open an issue with the broken URL and which stage it's in.
